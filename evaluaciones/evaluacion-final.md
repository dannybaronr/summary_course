# Evaluación final integradora

**Objetivo:** demostrar que puedes sintetizar una fuente, integrar varias, adaptar el resultado a una audiencia, verificar su fidelidad y enseñar el procedimiento.

**Duración recomendada:** 2–3 sesiones de hasta 45 minutos. Se prioriza la calidad del razonamiento sobre completar todo en una jornada.

## Parte A — Fuente individual
Elige una fuente manejable que no hayas resumido antes: artículo, capítulo, clase, discurso, entrevista, relato o documentación técnica.

Entrega:
1. Referencia completa o enlace.
2. Propósito y audiencia.
3. Idea central y tres ideas de apoyo.
4. Síntesis de 150–250 palabras.
5. Tres decisiones justificadas de inclusión o eliminación.
6. Una limitación o incertidumbre que la fuente no permita resolver.

## Parte B — Síntesis comparada
Selecciona una segunda fuente independiente sobre la misma pregunta.

| Pregunta | Fuente A | Fuente B | Síntesis |
|---|---|---|---|
| Afirmación principal | | | |
| Evidencia o razonamiento | | | |
| Coincidencias | | | |
| Diferencias o contradicciones | | | |
| Límites e incertidumbres | | | |

Redacta una conclusión que no fuerce el acuerdo y atribuya las afirmaciones relevantes.

## Parte C — Adaptación
Crea dos versiones para audiencias diferentes:
- Explicación para principiantes de hasta 150 palabras.
- Resumen ejecutivo o técnico de hasta 200 palabras.

Explica qué detalle cambiaste y qué información mantuviste obligatoriamente.

## Parte D — Verificación
Selecciona ocho afirmaciones de tus productos y registra:
- Afirmación.
- Fuente y ubicación del respaldo.
- Estado: respaldada, parcialmente respaldada, no respaldada o contradicha.
- Corrección necesaria.

## Parte E — Enseñanza
Diseña una microclase de 10–20 minutos para enseñar una técnica. Incluye objetivo observable, explicación, ejemplo, pregunta socrática, práctica, criterio de evaluación y feedback.

## Criterios de logro
- El resumen representa fielmente la fuente.
- La selección responde al propósito y audiencia.
- La lógica de la fuente no se altera.
- Las fuentes se comparan con justicia.
- Los límites e incertidumbres están visibles.
- Las afirmaciones importantes son trazables.
- La explicación sencilla conserva la precisión.
- La microclase permite observar si el aprendiz mejoró.

## Condición crítica
Una distorsión grave —inventar un resultado, invertir una negación, ocultar una limitación decisiva o atribuir una afirmación a la fuente equivocada— exige corrección y reintento, aunque la puntuación total sea alta.

## Reflexión final
1. ¿Qué error cometías al principio y cómo lo detectas ahora?
2. ¿Qué tipo de fuente todavía te cuesta más?
3. ¿Qué procedimiento usarás para comprobar fidelidad?
4. ¿Qué habilidad puedes enseñar ya y cuál requiere más práctica?

El dominio final se basa en productos y reintentos observables, no en la sensación de haber terminado el temario.
