# Sistema de evaluación del curso

La evaluación comprueba habilidades demostradas; no premia haber leído muchas páginas ni avanzar rápido. El sistema combina diagnóstico, práctica formativa, controles por nivel, evaluación final y seguimiento del desempeño docente.

## Documentos
- [Rúbrica general](rubrica.md): dimensiones, pesos y reglas de corrección.
- [Evaluación diagnóstica](evaluacion-diagnostica.md): punto de partida, sin nota de aprobación.
- [Controles por nivel](evaluacion-por-nivel.md): comprobaciones para avanzar y criterios de refuerzo.
- [Evaluación final integradora](evaluacion-final.md): proyecto con fuentes diversas.
- [Registro individual](registro-individual.md): evidencia acumulada y decisiones de tutoría.

## Ciclo de evaluación
1. Diagnosticar cómo resuelve el estudiante sin enseñarle primero la solución.
2. Enseñar y practicar mediante explicación, ejemplo, preguntas y primer intento.
3. Retroalimentar: identificar el error concreto, su causa probable y el siguiente paso.
4. Reintentar con una tarea nueva o variante, no copiando la solución modelo.
5. Registrar evidencia y dificultad en PROGRESO.md.
6. Comprobar transferencia a otro tipo de fuente o propósito.

## Principios de rigor
- Se evalúa el producto junto con la justificación de decisiones.
- La ortografía no pesa más que la fidelidad y la comprensión, salvo que la tarea evalúe escritura profesional.
- No se exige memorizar terminología antes de comprender el concepto.
- Un puntaje alto no compensa una distorsión crítica.
- «No sé todavía» o «la fuente no permite concluirlo» son respuestas válidas cuando están justificadas.
- El tiempo máximo organiza el trabajo; no es motivo para fingir comprensión.
- Una lección se marca como dominada solo con evidencia; las competencias centrales se comprueban más de una vez.

## Cuándo avanzar
Avanzar no significa no volver atrás. El tutor puede recomendar seguir si el núcleo está claro y programar una revisión breve; recomienda refuerzo cuando el error altera la idea central, la relación lógica, la atribución o el grado de certeza.

## Uso con ChatGPT
Responde en la conversación usando el número de lección y el producto solicitado. No necesitas copiar el curso completo. Si incorporas una fuente externa, comparte el enlace, archivo o fragmento necesario, según disponibilidad y permisos. El tutor devolverá observaciones y actualizará GitHub después de revisar evidencia real; debe verificar que el archivo haya quedado actualizado.
