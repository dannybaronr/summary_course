## Cómo avanzar
1. Abrí la lección correspondiente y resolvé primero la práctica sin mirar la clave.
2. Contrastá tu respuesta con la fuente original.
3. Usá la clave para detectar diferencias, no para copiar una respuesta modelo.
4. Registrá la evidencia y el siguiente paso en [PROGRESO.md](../PROGRESO.md).

**Importante:** las lecciones y claves se revisaron como material didáctico, pero el dominio del estudiante sigue pendiente de evidencia real.
