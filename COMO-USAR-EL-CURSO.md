# Cómo usar el curso y retomar después de una pausa

## Regla principal
No necesitas recordar todo de memoria. Antes de cada sesión, abre `PROGRESO.md` y localiza la próxima acción concreta. Ese archivo es la referencia del estado del curso.

## Rutina de una sesión (30–45 minutos)
1. **Retomar (3 min):** leer el último registro y decir qué recuerdas.
2. **Aprender (8–10 min):** leer la lección; anotar términos que no entiendas.
3. **Ver un ejemplo (5 min):** explicar por qué el ejemplo conserva unas ideas y omite otras.
4. **Practicar (10–15 min):** resolver sin mirar una respuesta modelo.
5. **Revisar (5–10 min):** comparar con la fuente y corregir.
6. **Registrar (2 min):** anotar evidencia, dificultad y siguiente paso.

## Cómo estudiar conmigo
Puedes iniciar una sesión diciendo:
> Continuemos el curso de síntesis desde GitHub. Lee PROGRESO.md, identifica la siguiente acción y enséñame la lección pendiente sin saltarte los fundamentos.

Si ya hiciste un ejercicio, pega tu respuesta o adjunta tus notas. No hace falta volver a explicar todo el contexto.

## Cómo se guardará el progreso
Después de una sesión:
1. Revisamos la respuesta y acordamos qué evidencia demuestra.
2. Actualizamos `PROGRESO.md`.
3. Si la lección necesita correcciones o nuevos ejemplos, actualizamos su archivo.
4. Si usamos una fuente nueva, la añadimos a `biblioteca-de-fuentes.md` con título, autor o institución, enlace, tipo y propósito.
5. Dejamos una próxima acción explícita.

La conexión con GitHub no guarda automáticamente todos los mensajes. El avance se debe registrar mediante una actualización real del repositorio; se confirmará cuando se haya hecho.

## Cuaderno personal opcional
Puedes guardar en GitHub un archivo `notas/diario.md` con tus propias respuestas. Si el repositorio es público, no pongas allí información personal sensible. Para ejercicios personales conviene un repositorio privado.

## Cómo se corrige
La retroalimentación debe incluir:
- qué entendiste bien;
- qué parte de la fuente respalda esa lectura;
- qué falta, sobra o está distorsionado;
- por qué importa;
- cómo revisarlo;
- una nueva oportunidad para aplicar el aprendizaje.

No se confunde un error puntual con falta de capacidad. Se usa para identificar qué concepto necesita otra explicación.

## Regla de pausa
Si pasan semanas sin estudiar, no reiniciar desde cero automáticamente. Revisar el último objetivo, hacer un ejercicio corto de recuperación y decidir:
- continuar si se mantiene la habilidad;
- hacer un repaso si hay vacilación;
- volver a una lección anterior si reaparece una dificultad fundamental.

## Qué significa “experto”
No significa conocer una fórmula única. Significa seleccionar con criterio, preservar fidelidad, reconocer límites, adaptar el resultado al propósito y poder enseñar el proceso a otra persona.
